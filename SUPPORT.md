# Support

If you're having trouble with Vortex, these are the best places to start:

- **[Vortex Wiki](https://github.com/Nexus-Mods/Vortex/wiki)** for the knowledge
  base, articles and troubleshooting guides.
- **[Vortex Forum](https://forums.nexusmods.com/index.php?/forum/4306-vortex-support/)**
  for support questions, where the community and the team can help.
- **[Discord](https://discord.gg/nexusmods)** for quicker back-and-forth with
  other users and the team.

Please use those rather than opening a GitHub issue for help with using Vortex,
mod installation problems, or questions about a specific game. Issues here are
for bugs and feature requests, and support questions get a faster answer on the
forum or Discord.

## Which versions we support

We accept bug reports against the current stable release and the current beta. If you're on an older
version, update first: the bug may already be fixed, and older versions aren't supported.

See [RELEASES.md](RELEASES.md) for the full policy, including how long extension and backend APIs stay
available after they're deprecated.

Found an actual bug? Open a
[bug report](https://github.com/Nexus-Mods/Vortex/issues/new?template=bug_report.md).

Found a security issue? See [SECURITY.md](SECURITY.md) instead, and please don't
report it publicly.
